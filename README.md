# Python Tetris

A classic Tetris game built from scratch using Python.

## Features

* 🎮 Classic Tetris gameplay
* ⬅️➡️ Move pieces left and right
* 🔄 Rotate pieces
* ⬇️ Drop pieces
* 🧹 Clear completed lines
* 🏆 Score tracking
* 💀 Game-over detection

## Controls

| Key     | Action       |
| ------- | ------------ |
| `←`     | Move left    |
| `→`     | Move right   |
| `↓`     | Move down    |
| `↑`     | Rotate piece |
| `Space` | Drop piece   |

## Technologies

* Python

## How to Run

1. Clone this repository:

```bash
git clone <your-repository-url>
```

2. Open the project folder.

3. Run the Python file:

```bash
python tetris.py
```
